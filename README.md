## About the Project

**GDGOC NFSU Cybersecurity Poster Studio** is an independent student-developed project designed to simplify promotional content creation for the cybersecurity community.

The platform aims to provide an accessible design workspace where students and event organizers can create professional posters using customizable templates, visual assets, backgrounds, typography and branding tools.

Instead of designing every promotional poster from scratch, users can customize layouts and create content suited to different technical events and social media platforms.

## Features

### 🎨 Background Studio
- Solid colour backgrounds.
- Custom colour combinations.
- Linear and radial gradients.
- Gradient customization.
- Background patterns and effects.
- Background presets.
- Transparent and no-background options.

### 🖼️ Image Library
- Cybersecurity and technology imagery.
- Programming and terminal visuals.
- Digital forensics imagery.
- Abstract technology backgrounds.
- Image search and category filters.
- Custom image uploads.
- Image previews and selection.

### 🧩 Independent Image Editing
- Separate hero images and background images.
- Decorative image elements.
- Image cropping and resizing.
- Rotation and positioning.
- Opacity and visual adjustments.
- Independent image replacement.

### 🔤 Typography Studio
- Customizable font families.
- Font size and weight controls.
- Letter spacing and line height.
- Text alignment and positioning.
- Text colours and effects.
- Font pairing presets.
- English and Hindi typography support.

### 🧱 Design Themes and Templates
Designed for different cybersecurity and technology events, including:
- CTF competitions.
- Ethical hacking workshops.
- Cybersecurity seminars.
- Technical sessions.
- Hackathons.
- Guest speaker events.
- Student recruitment campaigns.
- Community announcements.

### 🏷️ Branding and Campus Campaigns
- Custom logo uploads.
- Brand colour configuration.
- Campus-specific information.
- Reusable branding assets.
- Multi-campus campaign design.

### 📤 Export and Sharing
- Social media poster dimensions.
- PNG and JPEG export.
- Custom canvas dimensions.
- Poster preview and quality checks.

*Feature availability depends on the current implementation and configuration of the application.*

## Getting Started

### Use the Application

1. Open the application.
2. Choose a poster template or start a new design.
3. Customize the background.
4. Add hero images and decorative elements.
5. Edit text and typography.
6. Add relevant branding and event information.
7. Preview the design.
8. Export the finished poster using an available format.
